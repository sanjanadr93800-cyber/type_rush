## ⚡ TYPE RUSH – Analog Clock Typing Speed Tester

🚀 A Creative Typing Speed Test Application Using React JS

## 📌 About the Project

Type Rush is an interactive and user-friendly typing speed tester application developed using React JS. It helps users measure and improve their typing speed, accuracy, and overall typing performance through a 60-second typing challenge.

The application features a unique analog clock interface, a digital countdown timer, real-time typing progress, and automatic performance calculation. When users click the Start Test button, they are navigated to a separate typing test page. After completing the test, the application displays the final results on a dedicated results page.

## 🎯 Objectives

- To improve users' typing speed and accuracy.
- To provide an interactive typing practice platform.
- To calculate Words Per Minute (WPM).
- To display real-time typing progress.
- To provide a simple and attractive user interface.
- To evaluate typing performance within 60 seconds.

## ✨ Features

- 🕒 Analog Clock: Attractive clock design with numbers and clock hands.
- ⏱️ 60-Second Countdown: A timer for the typing challenge.
- 🚀 Start Test: Navigate from the home dashboard to the typing page.
- ⌨️ Typing Challenge: Practice typing with randomly selected paragraphs.
- ⚡ Live WPM: Calculate typing speed in Words Per Minute.
- 🎯 Accuracy Tracking: Calculate correctly typed characters.
- 📊 Progress Bar: Display typing progress in real time.
- 🏆 Result Dashboard: Display final typing performance.
- 🔄 Try Again: Restart the typing challenge.
- 📱 Responsive Design: Supports desktop and mobile screens.

## 📊 Performance Calculations

Words Per Minute (WPM)

WPM measures the number of standard five-character words typed per minute.

Formula:

WPM = (Correct Characters / 5) / Time in Minutes

Typing Accuracy

Accuracy measures the percentage of correctly typed characters.

Formula:

Accuracy = (Correct Characters / Total Typed Characters) × 100
